# Student Management

Ứng dụng quản lý sinh viên đơn giản chạy trên terminal (Command Line), được viết bằng ngôn ngữ Python.

Dự án mẫu được thiết kế ngắn gọn, dễ đọc, phù hợp làm bài tập thực hành Git và lập trình Python cơ bản.

## 1. Yêu cầu môi trường
- Python 3.8 trở lên (không cần cài đặt thêm thư viện bên ngoài).

## 2. Hướng dẫn chạy chương trình

1. Mở terminal hoặc Command Prompt và di chuyển vào thư mục dự án:
   ```bash
   cd student-management
   ```

2. Chạy ứng dụng bằng lệnh:
   ```bash
   python main.py
   ```

## 3. Các chức năng chính
- **1. Xem danh sách sinh viên**: Hiển thị bảng mã và tên sinh viên hiện có.
- **2. Thêm sinh viên**: Nhập mã và tên sinh viên mới (tự động kiểm tra trùng mã).
- **3. Xóa sinh viên**: Xóa sinh viên theo mã.
- **4. Thoát**: Thoát khỏi chương trình.

## 4. Cấu trúc thư mục
```text
student-management/
├── .gitignore
├── README.md
└── main.py
```
